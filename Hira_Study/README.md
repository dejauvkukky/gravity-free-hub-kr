# 🌸 히라가나 마스터 (Hiragana Master)

히라가나 읽기 완성 및 단어 마스터를 위한 인터랙티브 학습 웹 애플리케이션입니다.

## 📖 단계별 학습 로드맵
1. **1단계: 50음도 기본 청음 (46자)** - あ행부터 わ/を/ん까지 행별 정복
2. **2단계: 탁음 & 반탁음 (25자)** - が/ざ/だ/ば/ぱ행의 소리 변화 규칙
3. **3단계: 특수음 (요음/촉음/장음/발음)** - きゃ/しゅ/ちょ, っ, ー, ん
4. **4단계: 실전 단어 읽기** - 일상 필수 단어 100+개로 읽기 트레이닝
5. **5단계: 퀴즈 & 스피드 매칭 챌린지** - 플래시카드, 4지선다, 카드 매칭, 따라쓰기
