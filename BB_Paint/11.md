안티그래비티(Antigravity) IDE 에이전트에게 그대로 복사하여 입력하거나 단계별로 지시할 수 있도록 설계된 **모바일 4인 P2P 영역 칠하기 게임(3D Splatoon-Lite) 개발지시서**입니다.

단일 정적 웹 환경에서 별도의 백엔드 서버 구축 없이 동작하도록 아키텍처와 예외 처리 규칙을 엄격하게 정의했습니다.

## 1. 프로젝트 개요 및 기술 스택

- **프로젝트명:** 3D P2P Turf Clash (가제)
- **플랫폼:** 모바일 웹 브라우저 (세로 9:16 또는 가로 반응형 풀스크린, 터치 인터페이스 전용)
- **핵심 기술 스택:**
  - **렌더링:** Three.js (CDN 기반, ES Modules)
  - **네트워크:** PeerJS (WebRTC DataChannel 기반 P2P, 무료 공개 시그널링 서버 활용)
  - **아키텍처:** 서버리스 정적 페이지 구조 (`index.html`, `style.css`, `app.js`)
- **캐릭터 표현 방식:** 3D 공간 내 2D 투명 PNG 스프라이트 빌보드(Billboard) 처리 및 이동 시 코사인 바운스 애니메이션 적용

## 2. 디렉토리 및 에셋 규격

프로젝트 루트 경로에 아래 구조로 파일을 배치합니다. (이미지 파일이 없을 경우를 대비해 코드 내에 Canvas API 기반 Fallback 텍스처 자동 생성 로직을 반드시 포함합니다.)

- `index.html`: 뷰포트 메타태그(`user-scalable=no`), UI 레이어(로비, HUD, 결과창), Three.js 및 PeerJS CDN 로드
- `style.css`: `touch-action: none`, `overscroll-behavior: none`, 모바일 풀스크린 레이아웃
- `app.js`: 게임 엔진, P2P 호스트/클라이언트 상태 동기화, 가상 조이스틱 제어 통합 스크립트
- `assets/player_1.png` \~ `player_4.png`: 투명 배경(Alpha Channel) 캐릭터 이미지 (권장 규격: 512x512px)

## 3. 핵심 아키텍처 및 P2P 네트워크 명세

방장(Host) 브라우저가 인게임 서버(Authoritative Host) 역할을 수행하여 데이터 정합성을 유지합니다.

- **룸 코드 매칭 시스템:**
  - 방장이 방 생성 시 `TC-XXXX` (4자리 난수 숫자) 형태의 Peer ID를 생성하여 대기실 화면에 표시합니다.
  - 게스트(최대 3명)는 4자리 숫자만 입력하면 내부적으로 `TC-XXXX` ID로 매칭되어 방장의 Peer에 연결(`peer.connect`)됩니다.
- **데이터 패킷 경량화 규격 (JSON):**
  - **이동 패킷 (Guest → Host, 20Hz):** `{ type: 'MOVE', id: playerIndex, x: float, z: float, vx: float, vz: float }`
  - **상태 브로드캐스트 (Host → All Guests, 20Hz):** `{ type: 'STATE', players: [...], changedTiles: [[tileIdx, colorIdx], ...], timeLeft: int }`
  - **전체 타일 동기화:** 초기 진입 또는 패킷 유실 보정을 위해 3초 주기로 전체 그리드 배열(`Uint8Array(900)`) 스냅샷을 전송합니다.

## 4. 인게임 메커니즘 명세

- **3D 경기장 (Grid Map):**
  - `30 x 30` 격자(총 900개 타일, 타일당 크기 `1 x 0.2 x 1`)를 `THREE.InstancedMesh` 단일 드로우콜(Draw Call)로 렌더링하여 모바일 발열 및 프레임 저하를 방지합니다.
  - 기본 타일 색상은 밝은 회색(`#E0E0E0`)이며, 외곽에는 이탈 방지용 반투명 가드레일을 배치합니다.
- **플레이어 고유 색상 및 스폰 위치:**
  - **1P (Host):** Red (`#FF3B30`) / 좌측 상단 `(-12, -12)`
  - **2P (Guest 1):** Blue (`#007AFF`) / 우측 하단 `(12, 12)`
  - **3P (Guest 2):** Yellow (`#FFCC00`) / 우측 상단 `(12, -12)`
  - **4P (Guest 3):** Green (`#34C759`) / 좌측 하단 `(-12, 12)`
- **2D 캐릭터 빌보드 &amp; 모션:**
  - `THREE.Sprite` 또는 카메라 각도에 고정된 `PlaneGeometry`를 사용합니다.
  - 이동 벡터(`vx`) 방향에 따라 텍스처 좌우 반전(`flipX`)을 적용하고, 이동 중일 때 Y축 위치를 `Math.abs(Math.sin(time `*`  12))  `*` 0.3`으로 흔들어 통통 튀는 보행감을 구현합니다.
- **색칠 판정 (Paint Logic):**
  - 각 플레이어의 현재 월드 좌표 `(x, z)`를 그리드 배열 인덱스 `(row, col)`로 변환하여, 반경 1.2타일 이내의 타일을 즉시 해당 플레이어의 색상으로 덮어씁니다.
  - 실시간으로 각 색상의 타일 개수를 집계하여 상단 HUD 게이지 바에 점유율(%)을 표시합니다.

   - 만약 로컬에 이미지 파일이 없거나 로드에 실패할 경우, 에러가 나지 않도록 HTML5 Canvas로 귀여운 원형 슬라임 캐릭터와 눈동자를 동적으로 그려서 기본 텍스처로 사용하는 Fallback 함수를 반드시 작성해줘.

### Phase 2: PeerJS 기반 서버리스 4인 P2P 로비 및 실시간 상태 동기화 연동

Plaintext

```
Phase 1에서 만든 코드에 PeerJS(CDN)를 연동하여 별도 서버 없이 최대 4인이 동시에 플레이할 수 있는 P2P 멀티플레이 기능을 추가해줘.

[핵심 요구사항]
1. 시작 로비 UI 및 룸 코드 시스템:
   - 게임 시작 전 화면 중앙에 모던한 글래스모피즘 스타일의 로비 오버레이 UI를 만들어줘.
   - [방 만들기(Host)] 버튼을 누르면 4자리 랜덤 숫자(예: 4829)를 생성하고 내부 Peer ID를 `TC-4829`로 등록한 뒤, 화면에 "방 코드: 4829"와 현재 접속 인원(1/4 ~ 4/4) 목록을 표시해줘. 방장은 인원이 1명 이상일 때 언제든 [게임 시작]을 누를 수 있어.
   - [방 참가하기(Guest)] 영역에는 4자리 숫자 입력창과 [입장] 버튼을 두고, 입력 시 `TC-입력숫자` 호스트에 WebRTC DataChannel로 연결해줘.

2. Authoritative Host 동기화 구조:
   - 방장(1P)이 게임 상태(타일 배열 900개, 남은 시간 60초, 1P~4P 위치)의 마스터 권한을 가진다.
   - 게스트(2P~4P)는 자신의 조이스틱 이동 좌표와 속도 벡터를 50ms(20Hz) 주기로 방장에게 전송하고, 로컬 화면에서는 지연 없이 즉시 이동(Client-side Prediction)시켜줘.
   - 방장은 게스트들의 위치를 수신해 타일 색칠 판정을 계산하고, 변경된 타일 인덱스 목록(`[tileIndex, playerId]`)과 전체 플레이어 좌표를 50ms 주기로 모든 게스트에게 브로드캐스트해줘.
   - 원격 플레이어들의 위치는 끊겨 보이지 않도록 `lerp` 보간을 적용해 부드럽게 이동시켜줘.

```

## 6. 실전 테스트 및 배포 체크리스트

- **로컬 및 모바일 기기 간 테스트 방법:**
  - 안티그래비티 IDE의 로컬 프리뷰 서버를 실행한 뒤, PC 브라우저 창 2개와 스마트폰 브라우저를 동시에 띄워 방 코드(4자리)로 접속이 즉시 이루어지는지 확인합니다.
  - 모바일 브라우저에서 WebRTC가 정상 작동하려면 배포 환경이 `HTTPS`이거나 로컬호스트(`localhost`)여야 합니다. 외부 스마트폰 테스트 시에는 GitHub Pages, Vercel, Cloudflare Pages 등 무료 정적 호스팅에 올리거나 IDE의 포트 포워딩(HTTPS 터널링) 기능을 활용하십시오.
- **방화벽(NAT) 이슈 대응:**
  - 기본 PeerJS 설정에는 Google의 무료 STUN 서버(`stun:stun.l.google.com:19302`)를 명시적으로 옵션에 넣어주도록 코드가 생성되었는지 확인하십시오. (동일 Wi-Fi 또는 일반 LTE/5G 환경에서 90% 이상 즉시 연결됩니다.)
